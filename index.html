// فێربوونی دۆکەر — لە سفرەوە بۆ ئاستی بەرز

دۆکەر بە تەواوی فێربە

هەموو ئەو شتانەی پێویستتە بۆ تێگەیشتن لە دۆکەر — بۆچی بەکاردێت، چییە، و چۆن بەکاری دەهێنی. هەر کۆدێک بە تەواوی ڕوون کراوەتەوە.

سفر → بەرز ڕوونکردنەوەی هەموو کۆدێک نەخشەی دەستکرد ڕووکاری تاریک و ڕووناک

چۆن ئەم لاپەڕە بخوێنیتەوە

  • لە سەرەوە بۆ خوارەوە بخوێنەوە — هەر بەش لەسەر بەشی پێشوو بنیات دەنرێت.
  • هەموو کۆدێک بە دەست بنووسە. تەنها خوێندنەوە فێرت ناکات.
  • ماوس بخەرە سەر بلۆکی کۆد، دوگمەی copy دەردەکەوێت.
  • هەموو شتێک کە بە فۆنتی مۆنۆ نیشان دراوە، دەرئەنجامی تێرمیناڵە — نەک کۆدی نووسراو.
یاسا ئەگەر کۆدێک شکستی هێنا، هەڵەکە بە دەنگی خۆت بخوێنەوە. هەڵەکانی دۆکەر زۆر ڕوونن — زۆربەی کات، چاککردنی کێشە تەنها خوێندنەوەی دروستی هەڵەیە.

01بۆچی دۆکەر بەکاردەهێنین؟

پێش دۆکەر، هەر گەشەپێدەرێک ئەم کێشەیەی هەبوو: کۆدەکە لە کۆمپیوتەری خۆیدا کاردەکات، بەڵام لە سێرڤەردا نا. ئەمە بە «لای من کاردەکات» ناسرابوو.

کێشەی کۆن (بێ دۆکەر): ┌──────────────────────┐ ┌──────────────────────┐ │ کۆمپیوتەری تۆ │ │ سێرڤەر │ │ Node 20 │ ≠ │ Node 16 │ │ Ubuntu 24 │ │ Ubuntu 20 │ │ PostgreSQL 16 │ │ PostgreSQL 12 │ └──────────────────────┘ └──────────────────────┘ کاردەکات دەکەوێت ────────────────────────────────────────────────────────── چارەسەری دۆکەر: ┌──────────────────────┐ ┌──────────────────────┐ │ کۆمپیوتەری تۆ │ │ سێرڤەر │ │ ┌────────────────┐ │ │ ┌────────────────┐ │ │ │ کۆنتەینەر │ │ = │ │ کۆنتەینەر │ │ │ │ (وەک خۆی) │ │ │ │ (وەک خۆی) │ │ │ └────────────────┘ │ │ └────────────────┘ │ └──────────────────────┘ └──────────────────────┘ هەمان ژینگە هەمان ئەنجام

حەوت هۆکار

◈
هەمان ژینگە

هەر کوێ کۆنتەینەرەکە بەکاربهێنی، هەمان ئەنجام دەگریت. جیاوازی نێوان کۆمپیوتەری تۆ و سێرڤەر نامێنێت.

◈
خێرایی زۆر

کۆنتەینەر لە چەند ساتێکدا هەڵدەستێت، بەڵام ڤێرچواڵ مەشین چەند خولەکێکی پێویستە.

◈
کێشی کەم

کۆنتەینەر بە مێگابایت دەپێورێت، نەک بە گیگابایت. دەیەها کۆنتەینەر لەسەر یەک سێرڤەر کاردەکەن.

◈
گواستنەوەی ئاسان

وێنەکەت دروست دەکەیت و بۆ هەر شوێنێک دەینێریت — لۆکاڵ، سێرڤەر، AWS، GCP. هەموو پێداویستییەکان لەگەڵ خۆیەتی.

◈
جیاکردنەوە

هەر ئەپلیکەیشنێک لە کۆنتەینەری خۆیدا. یەکێک شکست هێنا، ئەوانی تر بەردەوام دەبن.

◈
گەڕاندنەوەی ئاسان

هەر وێنەیەک تۆمارێکی نەگۆڕە. کۆنتەینەرێک بشکێت، لە چەند ساتێکدا یەکێکی نوێ هەڵدەستێت.

◈
سەربەخۆ لە سیستەم

پێویست ناکات لەسەر سێرڤەرەکەت هەموو ئامرازەکان دابمەزرێنی. دۆکەر هەمووی لەناو خۆیدا هەڵدەگرێت.

کورتە دۆکەر ڕێگەیەکە بۆ پێکەوە پێچانەوەی ئەپلیکەیشن لەگەڵ هەموو ئەو شتانەی پێویستی پێیەتی — بۆ ئەوەی لە هەر کوێیەک بێت بە هەمان شێوە کار بکات.

02دۆکەر چییە؟

دۆکەر پلاتفۆرمێکە کە یارمەتیت دەدات کۆنتەینەر دروست بکەیت، هەڵی بگریت و بەڕێوەی ببەیت. کۆنتەینەر لە ڕاستیدا پرۆسێسێکی ئاسایی لینوکسە کە ژینگەیەکی سەربەخۆی پێدراوە — وەک ئەوەی تەنها خۆی لەسەر کۆمپیوتەرەکە بێت.

کۆنتەینەر چۆن کاردەکات؟ ┌────────────────────────────────────────────────────┐ │ سیستەمی کارپێکردنی خانەخوێ │ │ (Linux Kernel) │ │ │ │ ┌──────────────┬──────────────┬──────────────┐ │ │ │ Namespaces │ Cgroups │ UnionFS │ │ │ │ (جیاکردنەوە)│(سنووری سەرچاوە)│(چینی فایل) │ │ │ └──────────────┴──────────────┴──────────────┘ │ │ │ │ ┌──────────┐ ┌──────────┐ ┌──────────┐ │ │ │ کۆنتەینەر │ │ کۆنتەینەر │ │ کۆنتەینەر │ │ │ │ A │ │ B │ │ C │ │ │ │ (پرۆسێس) │ │ (پرۆسێس) │ │ (پرۆسێس) │ │ │ └──────────┘ └──────────┘ └──────────┘ │ └────────────────────────────────────────────────────┘ هەر کۆنتەینەرێک = پرۆسێس + Namespace + Cgroup

چوار چەمکی سەرەکی

▣
وێنە (Image)

فایلێکی نەگۆڕ کە هەموو پێداویستییەکانی تێدایە. وەک «پلان» وایە. چەندین جار دەتوانرێت بەکاربهێنرێت.

▣
کۆنتەینەر

نموونەیەکی کارای وێنەیە. وەک «ئۆبجێکت» وایە. دەتوانرێت هەڵبستێت، بوەستێت، و بسڕدرێتەوە.

▣
Dockerfile

دەقێک کە هەنگاو بە هەنگاو ڕوون دەکاتەوە چۆن وێنەیەک دروست بکەیت. وەک «ڕێچکە» وایە.

▣
Registry

شوێنێک بۆ هەڵگرتنی وێنەکان — Docker Hub، GHCR، یان سێرڤەری تایبەت بە خۆت.

مۆدێلی بیرکردنەوە وێنە = نەگۆڕ. کۆنتەینەر = تێکدەر. هەر شتێک کە دەبێت بمێنێتەوە، دەبێت لە دەرەوەی کۆنتەینەر بێت — لە ڤۆلیووم یان بنکەدراوەیەکدا.

03جیاوازی نێوان ڤێرچواڵ مەشین و کۆنتەینەر

زۆر کەس بە هەڵە وا دەزانن کۆنتەینەر و ڤێرچواڵ مەشین یەک شتن. بەڵام جیاوازییەکی زۆر بنەڕەتییان هەیە.

04پێکهاتەی دۆکەر

دۆکەر لە سێ بەشی سەرەکی پێکهاتووە:

┌─────────────────────────────────────────┐ │ CLI (docker) │ │ ◇ تۆ ئەمە بەکاردەهێنی │ └─────────────────┬───────────────────────┘ │ HTTP / Unix socket ▼ ┌─────────────────────────────────────────┐ │ Docker Daemon (dockerd) │ │ ◇ کارەکانی سەرەکی دەکات │ │ ┌────────────┬──────────┬───────────┐ │ │ │ containerd │ runc │ BuildKit │ │ │ │(بەڕێوەبردن)│(جێبەجێکردن)│(دروستکردن)│ │ │ └────────────┴──────────┴───────────┘ │ └─────────────────┬───────────────────────┘ │ ▼ ┌─────────────────────────────────────────┐ │ Registry (Docker Hub, GHCR, ...) │ │ ◇ وێنەکان لێرە هەڵدەگیرێن │ └─────────────────────────────────────────┘

سێ بەشەکە بە کورتی

پێکهاتە · سێ بەش
CLI (docker) ئامرازی فەرمان. تۆ docker run دەنووسیت، ئەمیش داواکارییەک دەنێریت بۆ daemon.
Daemon (dockerd) دڵی دۆکەر. وێنەکان هەڵدەگرێت، کۆنتەینەرەکان دروست دەکات، شەبەکە بەڕێوەدەبات.
Registry کۆگای وێنەکان. Docker Hub، GHCR، ECR — هەموویان registryن.
گرنگ CLI و daemon بە HTTP قسە دەکەن لە ڕێگەی Unix socket (/var/run/docker.sock). ئەمە واتە دەتوانیت دۆکەر لە ڕیمۆت بەکاربهێنیت — تەنها socketەکە بە -H دیاری بکە.

05دامەزراندن و پشکنین

پێش هەر شتێک، بزانە چی لە سیستمەکەتدا هەیە.

پشکنینی وەشان

$ docker --version
$ docker version
$ docker info
$ docker compose version
ڕوونکردنەوەی هەر فەرمانێک
docker --version تەنها وەشانی CLI نیشان دەدات. خێرایە، پەیوەندی بە daemon ناکات.
docker version هەم CLI و هەم daemon (Server). ئەگەر Server بەتاڵ بوو، daemon کار ناکات.
docker info زانیاری زۆر — storage driver، cgroup، runtimes، ژمارەی کۆنتەینەر. بۆ دۆزینەوەی کێشە زۆر بەکەڵکە.
compose version پشکنینی pluginی Compose. لە وەشانی ٢ەوە بەشێکە لە CLI، نەک باینەری جیاواز.

تاقیکردنەوەی یەکەم کۆنتەینەر

$ docker run --rm hello-world
Unable to find image 'hello-world:latest' locally latest: Pulling from library/hello-world Hello from Docker! This message shows that your installation appears to be working correctly.
ئەم کۆدە چی دەکات؟
docker run کۆنتەینەرێکی نوێ دروست دەکات و هەڵدەستێنێت.
--rm کاتێک کۆنتەینەر کۆتایی هات، خۆکارانە بیسڕەوە. بەبێ ئەمە، کۆنتەینەری مردوو لە docker ps -aدا دەمێنێتەوە.
hello-world ناوی وێنە. دۆکەر سەرەتا لە لۆکاڵ دەیگەڕێت، ئەگەر نەبوو لە Docker Hub دایگرێت.

دەستووری بەکارهێنەر (ئەگەر پێویست بوو)

$ sudo usermod -aG docker $USER
$ newgrp docker
ئاسایش ئەندامبوون لە گرووپی docker واتە دەسەڵاتی root لەسەر خانەخوێ. لەسەر سێرڤەری هاوبەش، دۆکەری بێ‌root (rootless) بەکاربهێنە.

06وێنەکان (Images)

وێنە لە چەند چینێکی نەگۆڕ (read-only) پێکهاتووە کە لەسەر یەک دانراون، لەگەڵ فایلێکی ڕێکخستنی JSON. هەر فەرمانێکی Dockerfile کە فایلەکان دەگۆڕێت، چینێکی نوێ دروست دەکات.

پێکهاتەی وێنەیەک: ┌─────────────────────────────┐ │ کۆنتەینەر (نووسراو) │ ← تەنها ئەمە دەگۆڕدرێت ├─────────────────────────────┤ │ چین ٤: CMD ["node","app"] │ ├─────────────────────────────┤ │ چین ٣: COPY . . │ ├─────────────────────────────┤ │ چین ٢: RUN npm install │ ├─────────────────────────────┤ │ چین ١: FROM node:20-alpine │ ← بنەڕەت └─────────────────────────────┘ هەموو چینەکان لە نێوان وێنەکاندا هاوبەشن. بۆیە داگرتنی nginx:alpine دوای alpine خێرایە!

داگرتن و بینین

$ docker pull nginx:1.27-alpine
$ docker image ls
$ docker image ls --format "table {{.Repository}}\t{{.Tag}}\t{{.Size}}"
ڕوونکردنەوە
docker pull وێنەکە لە registry دەگرێت و لە لۆکاڵ پاشەکەوت دەکات. ئەگەر پێشتر هەبوو، تەنها چینە نوێیەکان دەگرێت.
docker image ls لیستی هەموو وێنە لۆکاڵییەکان. هاوشێوەی docker images.
--format کۆنترۆڵی دەرئەنجام بە Go template. بۆ سکریپت و خواندن زۆر بەکەڵکە.

پشکنین و تێگەیشتن

$ docker image inspect nginx:1.27-alpine
$ docker image inspect -f '{{.Config.Cmd}}' nginx:1.27-alpine
$ docker history nginx:1.27-alpine
جیاوازی ئەم سێ فەرمانە
inspect هەموو زانیارییەک لەسەر وێنە — config، env، entrypoint، layers. دەرئەنجامەکی JSONی گەورەیە.
inspect -f تەنها بەشێکی دیاریکراو. بۆ نموونە .Config.Cmd تەنها CMDی وێنە نیشان دەدات.
history لیستی چینەکان بەپێی کات. فەرمانی هەر چینێک و قەبارەکەی. بۆ دۆزینەوەی چینە گەورەکە زۆر بەکەڵکە.

تاگ، سڕینەوە، پاککردنەوە

$ docker tag myapp:latest registry.example.com/team/myapp:1.0.0
$ docker image rm nginx:1.27-alpine
$ docker image prune -a
ئاستی بەرز latest درۆیە. وێنەکان بۆ بەرهەمهێنان بە تاگی دیاریکراو تاگ بکە، یان باشتر بە digest: nginx@sha256:.... Digest نەگۆڕە — هەمان بایت هەمیشە.

07کۆنتەینەرەکان

ئەم بەشە ئەوەیە کە ڕۆژانە پێویستت پێیەتی.

فلاگەکانی docker run

فلاگماناکاتێک بەکاریدەهێنی
-dلە پاشبنەما کار بکاتسێرڤەر، داتابەیس، هەر شتێکی بەردەوام
-itشێڵێکی کارلێککردوو بداتێدۆزینەوەی کێشە، کارکردن بە دەستی
--rmکۆنتەینەر بسڕەوە کاتێک کۆتایی هاتفەرمانەکانی کاتی، تاقیکردنەوە
--nameناوی جێگیرکاتێک دەتەوێت دواتر پەیوەندی پێوە بکەیت
-p H:Cپۆرتی خانەخوێ → کۆنتەینەردەستگەیشتن لە دەرەوە
-e K=Vگۆڕاوەی ژینگەڕێکخستن (نەخێر بۆ نهێنی)
-vڤۆلیووم یان bind mountداتای بەردەوام، کۆدی گەشەپێدان
--networkپەیوەندیکردن بە شەبەکەیەکچەند کۆنتەینەر پێویستە قسە بکەن
--restartسیاسەتی دووبارە هەڵسانەوەبەرهەمهێنان — unless-stopped
--memoryسنووری RAMهەمیشە لە بەرهەمهێنان

دەستپێکردن و بینین

$ docker run -d --name web -p 8080:80 nginx:1.27-alpine
$ docker ps
$ docker ps -a
$ docker ps -aq
جیاوازی ئەم سێ فەرمانە
docker ps تەنها کۆنتەینەرەکانی کارا. ئەگەر هیچ نیشان نەدرا، هیچ کۆنتەینەرێک ناچالاک نییە.
docker ps -a هەموو کۆنتەینەرەکان، لەوانە ئەوانەی مردوون. بۆ دۆزینەوەی کێشە زۆر گرنگە.
docker ps -aq تەنها IDی کۆنتەینەرەکان، بێ هێڵی سەرەوە. بۆ سکریپت زۆر بەکەڵکە.

چوونە ناوەوە و بینینی لۆگ

$ docker logs -f --tail 50 web
$ docker exec -it web sh
$ docker top web
$ docker stats
هەر یەکێک بۆ چییە
docker logs دەرئەنجامی پرۆسێسی سەرەکی. -f = شوێنکەوتنی زیندوو، --tail 50 = تەنها ٥٠ هێڵی کۆتایی.
docker exec فەرمانێک لەناو کۆنتەینەری کارا جێبەجێ دەکات. -it = شێڵی کارلێککردوو. لە Alpine sh بەکاربهێنە نەک bash.
docker top پرۆسێسەکانی ناو کۆنتەینەر لە ڕوانگەی خانەخوێوە. بۆ دڵنیابوون لەوەی پرۆسێسەکە هەیە.
docker stats بەکارهێنانی زیندووی CPU، RAM، شەبەکە. وەک top بەڵام بۆ کۆنتەینەرەکان. --no-stream بۆ یەک جار.

وەستان، سڕینەوە، کۆپیکردن

$ docker stop web
$ docker start web
$ docker restart web
$ docker rm web
$ docker rm -f web
$ docker cp web:/etc/nginx/nginx.conf ./nginx.conf
جیاوازی stop و rm
docker stop SIGTERM دەنێریت، دوای ١٠ چرکە SIGKILL. کۆنتەینەر دەمرێت بەڵام نامێنێتەوە.
docker start کۆنتەینەرێکی وەستاو دووبارە هەڵدەستێنێت. داتای ناوەوە دەمێنێتەوە (لە writable layer).
docker rm کۆنتەینەر دەسڕێتەوە. داتای writable layer لەناو دەچێت. پێویستە سەرەتا stop بکرێت.
docker rm -f stop + rm لە یەک فەرماندا. زۆر بەکەڵکە بەڵام ئاگاداربە — داتا لەناو دەچێت.
docker cp کۆپیکردنی فایل لە نێوان کۆنتەینەر و خانەخوێ. بۆ دەرهێنانی config یان لۆگ بەکەڵکە.

خولگەی ژیان

docker create ──► Created ──► docker start ──► Running │ docker pause │ docker stop ▼ Paused ──► Exited ──► docker rm ──► gone
تێبینی پرۆسێسی سەرەکی کۆنتەینەر PID 1ە لەناویدا. ئەگەر ئەو پرۆسێسە بمرێت، کۆنتەینەر دەمرێت — تەنانەت ئەگەر daemonێک لەناویدا هەڵدەستێنی. یەک کۆنتەینەر، یەک بەرپرسیارێتی.

08داتا — ڤۆلیووم و Bind Mount

کاتێک کۆنتەینەرێک دەسڕدرێتەوە، writable layerەکەی لەگەڵ خۆی دەبات. ئەگەر داتا دەبێت بمێنێتەوە، دەبێت لە دەرەوەی کۆنتەینەر بێت. سێ ڕێگا هەیە:

جۆرلە کوێیەبۆچی بەکاریدەهێنی
Named Volumeشوێنی بەڕێوەبراو لەلایەن دۆکەربنکەدراوە، فایلی بەکارهێنەر — داتای ڕاستەقینە
Bind Mountڕێچکەیەک لەسەر خانەخوێگەشەپێدانی لۆکاڵ، فایلی ڕێکخستن
tmpfsتەنها لە RAMنهێنییەکان، شوێنی کاتی، کاش

Named Volumes

$ docker volume create pgdata
$ docker volume ls
$ docker volume inspect pgdata
$ docker run -d --name db \
    -e POSTGRES_PASSWORD=secret \
    -v pgdata:/var/lib/postgresql/data \
    postgres:16-alpine
ڕوونکردنەوەی هەنگاوەکان
volume create ڤۆلیوومێک بە ناوی دیاریکراو دروست دەکات. دۆکەر بەڕێوەدەبات، تۆ پێویست ناکات ڕێچکەکە بزانیت.
volume inspect ناونیشانی ڕاستەقینەی لەسەر دیسکی خانەخوێ نیشان دەدات (/var/lib/docker/volumes/…).
-v name:/path ڤۆلیوومەکە بدە بە ڕێچکەیەکی ناو کۆنتەینەر. داتا لەوێ دەنووسرێت و دوای سڕینەوەی کۆنتەینەر دەمێنێتەوە.

Bind Mounts

$ docker run --rm -it \
    --mount type=bind,source="$(pwd)",target=/app,readonly \
    -w /app node:20-alpine sh
بۆچی --mount باشترە لە -v
--mount ڕوون و ئاشکرایە. ئەگەر ڕێچکەی سەرچاوە نەبوو، بە هەڵە ڕادەوەستێت. باشترە بۆ سکریپت.
-v کورتترە بەڵام ئەگەر ڕێچکە نەبوو، دۆکەر بەبێ مەودا فایلێک دروست دەکات. مەترسیدارە.
readonly کۆنتەینەر ناتوانێت بنووسێت. باشە بۆ فایلی ڕێکخستن و کۆدی گەشەپێدان.

پاشەکەوتکردنی ڤۆلیووم

# باکئەپ
$ docker run --rm -v pgdata:/data -v "$(pwd)":/backup alpine \
    tar czf /backup/pgdata-$(date +%F).tgz -C /data .

# گەڕاندنەوە
$ docker run --rm -v pgdata:/data -v "$(pwd)":/backup alpine \
    tar xzf /backup/pgdata-2024-01-01.tgz -C /data

ئەم کۆدە کۆنتەینەرێکی کاتی Alpine هەڵدەستێنێت کە دوو ڤۆلیوومی هەیە: /data (ڤۆلیوومی پاشەکەوت) و /backup (ڕێچکەی خانەخوێ). دواتر tar فایلەکان کۆپی دەکات.
