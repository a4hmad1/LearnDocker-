دۆکەر بە تەواوی فێربە

هەموو شتێک کە پێویستتە بۆ تێگەیشتن لە دۆکەر — لە بۆچی و چییەتیەوە تا هەموو کۆدەکان. هەر کۆدێک بە تەواوی ڕوونکراوەتەوە: بۆچی بەکاردێت، چۆن کاردەکات، و جیاوازی لەگەڵ کۆدەکانی تر چییە.

junior → senior ڕوونکردنەوەی هەموو کۆدێک نەخشەی بینراوی ASCII black & white terminal

چۆن ئەم لاپەڕە بەکاربهێنە

  • لە سەرەوە بۆ خوارەوە بخوێنەوە — هەر بەشێک لەسەر بەشی پێشوو بنیات دەنرێت.
  • هەموو کۆدێک بە دەست بنووسە، تەنها خوێندنەوە فێرکردن نییە.
  • ماوس بخەرە سەر بلۆکی کۆد → دوگمەی copy دەردەکەوێت → دایگری و لە تێرمیناڵی خۆت بلکێنە.
  • بلۆکەکانی خوارەوە بە فۆنتی مۆنۆ و پاشبنەمای تاریک — دەرئەنجامی تێرمیناڵن، نەک کۆدی نووسراو.
یاسا ئەگەر کۆدێک شکستی هێنا، هەڵەکە بە دەنگی خۆت بخوێنەوە. هەڵەکانی دۆکەر زۆر ڕوونن — ٨٠٪ی چاککردنی کێشەکان تەنها خوێندنەوەی دروستی هەڵەیە.

01بۆچی دۆکەر بەکاردەهێنین؟

پێش دۆکەر، کێشەیەکی گەورەی هەمیشەیی هەبوو کە بە «لای من کاردەکات!» (Works on my machine) ناسراوە. کۆدەکەت لە کۆمپیوتەری خۆتدا بە تەواوی کاردەکات، بەڵام کاتێک دەیکەیتە سێرڤەرێکی تر — شکست دەهێنێت. بۆچی؟

کێشەی کۆن (بێ دۆکەر): ┌────────────────────┐ ┌────────────────────┐ │ کۆمپیوتەری تۆ │ │ سێرڤەری بەرهەمهێنان │ │ Node 20 │ ≠ │ Node 16 │ │ Ubuntu 24 │ │ Ubuntu 20 │ │ PostgreSQL 16 │ │ PostgreSQL 12 │ │ libvips 8.15 │ │ libvips 8.9 │ └────────────────────┘ └────────────────────┘ "لای من کاردەکات" کۆدەکە دەکەوێت ──────────────────────────────────────────────────────── چارەسەری دۆکەر: ┌────────────────────┐ ┌────────────────────┐ │ کۆمپیوتەری تۆ │ │ سێرڤەری بەرهەمهێنان │ │ ┌──────────────┐ │ │ ┌──────────────┐ │ │ │ کۆنتەینەری │ │ = │ │ کۆنتەینەری │ │ │ │ تەواو وەک خۆی │ │ │ │ تەواو وەک خۆی │ │ │ └──────────────┘ │ │ └──────────────┘ │ └────────────────────┘ └────────────────────┘ هەمان ژینگە هەمان ئەنجام

حەوت هۆکاری سەرەکی

◈
١. هەمان ژینگە

هەر شوێنێک کۆنتەینەرەکە بەکاربهێنی، هەمان ئەنجامت دەست دەکەوێت. جیاوازی نێوان کۆمپیوتەری تۆ و سێرڤەر نامێنێت.

◈
٢. خێرایی زۆر

کۆنتەینەر لە چەند ساتێکدا هەڵدەستێت، بەڵام ڤێرچواڵ مەشین چەند خولەکێکی پێویستە. جیاوازی ١٠٠ ئەوەندە.

◈
٣. کێشی کەم

کۆنتەینەر بە مێگابایت دەپێورێت، نەک بە گیگابایت. بە دەیەها کۆنتەینەر لەسەر یەک سێرڤەر کاردەکەن.

◈
٤. دابەشکردنی ئاسان

وێنەکەت دروست دەکەیت و هەر شوێنێک دەینێریت — لۆکاڵ، سێرڤەر، AWS، GCP. هەموو پێداویستییەکان لەگەڵ خۆیەتی.

◈
٥. جیاکردنەوە

هەر ئەپلیکەیشنێک لە کۆنتەینەری خۆیدا. ئەگەر یەکێک شکست هێنا، ئەوانی تر بەردەوام دەبن.

◈
٦. گەڕاندنەوەی ئاسان

هەر وێنەیەک تۆمارێکی نەگۆڕە. کۆنتەینەرێک بشکێت، لە چەند ساتێکدا یەکێکی نوێ هەڵدەستێت.

◈
٧. سەربەخۆیی لە سیستەم

پێویست ناکات لەسەر سێرڤەرەکەت هەموو ئامرازەکان دابمەزرێنی. دۆکەر هەمووی لەناو خۆیدا هەڵدەگرێت.

کورتە دۆکەر شێوەیەکە بۆ پاکەتکردنی ئەپلیکەیشن لەگەڵ هەموو پێداویستییەکانی بۆ ئەوەی لە هەر شوێنێک بە هەمان شێوە کاربکات.

02دۆکەر چییە؟

دۆکەر پلاتفۆرمێکە بۆ دروستکردن، هەڵگرتن و بەڕێوەبردنی کۆنتەینەرەکان. کۆنتەینەر پرۆسێسێکی ئاسایی لینوکسە کە ژینگەیەکی جیاکراوەی پێدراوە — وەک ئەوەی تەنها ئەو لەسەر ئەو کۆمپیوتەرە بێت.

کۆنتەینەر چۆن کاردەکات؟ ┌─────────────────────────────────────────────────┐ │ سیستەمی کارپێکردنی خانەخوێ │ │ (Linux Kernel) │ │ ┌─────────────┬─────────────┬─────────────┐ │ │ │ Namespaces │ Cgroups │ UnionFS │ │ │ │ (جیاکردنەوە)│(سنووری سەرچاوە)│(چینەکانی فایل)│ │ │ └─────────────┴─────────────┴─────────────┘ │ │ ┌───────────┐ ┌───────────┐ ┌───────────┐ │ │ │ کۆنتەینەر │ │ کۆنتەینەر │ │ کۆنتەینەر │ │ │ │ A │ │ B │ │ C │ │ │ │ (پرۆسێس) │ │ (پرۆسێس) │ │ (پرۆسێس) │ │ │ └───────────┘ └───────────┘ └───────────┘ │ └─────────────────────────────────────────────────┘ هەر کۆنتەینەرێک = پرۆسێسێک + چەند namespace + سنووری cgroup

چوار چەمکی بنەڕەتی

▣
وێنە (Image)

فایلێکی نەگۆڕ کە هەموو پێداویستییەکانی تێدایە. وەک «پلان» یان «کلاس» وایە. دەتوانرێت چەندین جار بەکاربهێنرێت.

▣
کۆنتەینەر (Container)

نموونەیەکی کارای وێنەیە. وەک «ئۆبجێکت» وایە. دەتوانرێت هەڵبستێت، بوەستێت، و بسڕدرێتەوە.

▣
Dockerfile

دەقێک کە هەنگاو بە هەنگاو ڕوون دەکاتەوە چۆن وێنەیەک دروست بکەیت. وەک «ڕێچکە» وایە.

▣
Registry

شوێنێک بۆ هەڵگرتنی وێنەکان — وەک Docker Hub، GHCR، یان سێرڤەری تایبەت بە خۆت.

مۆدێلی بیرکردنەوە وێنە = نەگۆڕ. کۆنتەینەر = تێکدەر. هەر شتێک کە دەبێت بمێنێتەوە، دەبێت لە دەرەوەی کۆنتەینەر بێت — لە ڤۆلیووم، یان بنکەدراوەیەکدا.

04پێکهاتەی دۆکەر

دۆکەر لە سێ بەشێکی سەرەکی پێکهاتووە:

┌──────────────────────────────────────────────────┐ │ CLI (docker) │ │ ◇ تۆ ئەمە بەکاردەهێنی │ └──────────────────────┬───────────────────────────┘ │ HTTP / Unix socket ▼ ┌──────────────────────────────────────────────────┐ │ Docker Daemon (dockerd) │ │ ◇ کارەکانی سەرەکی دەکات │ │ ┌──────────────┬──────────────┬──────────────┐ │ │ │ containerd │ runc │ BuildKit │ │ │ │ (بەڕێوەبردن) │ (جێبەجێکردن) │ (دروستکردن)│ │ │ └──────────────┴──────────────┴──────────────┘ │ └──────────────────────┬───────────────────────────┘ │ ▼ ┌──────────────────────────────────────────────────┐ │ Registry (Docker Hub...) │ │ ◇ وێنەکان لێرە هەڵدەگیرێن │ └──────────────────────────────────────────────────┘

سێ بەشەکە بە کورتی

architecture · three components
CLI (docker) ئامرازی فەرمان. تۆ docker run دەنووسیت، ئەمیش داواکارییەک دەنێریت بۆ daemon.
Daemon (dockerd) دڵی دۆکەر. وێنەکان هەڵدەگرێت، کۆنتەینەرەکان دروست دەکات، شەبەکە بەڕێوەدەبات.
Registry کۆگای وێنەکان. Docker Hub، GHCR، ECR — هەموویان registryن.
گرنگ CLI و daemon بە HTTP قسە دەکەن لە ڕێگەی Unix socket (/var/run/docker.sock). ئەمە واتە دەتوانیت دۆکەر لە ڕیمۆت بەکاربهێنیت — تەنها socketەکە بە -H دیاری بکە.

05دامەزراندن و پشکنین

پێش هەر شتێک، دڵنیابە چی هەیە لە سیستمەکەتدا.

پشکنینی وەشان

$ docker --version
$ docker version
$ docker info
$ docker compose version
ڕوونکردنەوەی هەر فەرمانێک
docker --version تەنها وەشانی CLI نیشان دەدات. زۆر خێرایە، پەیوەندی بە daemon ناکات.
docker version هەم CLI و هەم daemon (Server). ئەگەر Server بەتاڵ بوو، daemon کار ناکات.
docker info زانیاری زۆر — storage driver، cgroup، runtimes، ژمارەی کۆنتەینەر. بۆ دۆزینەوەی کێشە زۆر بەکەڵکە.
docker compose version پشکنینی pluginی Compose. لە وەشانی ٢ەوە بەشێکە لە CLI، نەک باینەری جیاواز.

تاقیکردنەوەی یەکەم کۆنتەینەر

$ docker run --rm hello-world
Unable to find image 'hello-world:latest' locally latest: Pulling from library/hello-world Hello from Docker! This message shows that your installation appears to be working correctly.
ئەم کۆدە چی دەکات؟
docker run کۆنتەینەرێکی نوێ دروست دەکات و هەڵدەستێنێت.
--rm کاتێک کۆنتەینەر کۆتایی هات، خۆکارانە بیسڕەوە. بەبێ ئەمە، کۆنتەینەری مردوو لە docker ps -aدا دەمێنێتەوە.
hello-world ناوی وێنە. دۆکەر سەرەتا لە لۆکاڵ دەیگەڕێت، ئەگەر نەبوو لە Docker Hub دایگرێت.

دەستووری بەکارهێنەر (ئەگەر پێویست بوو)

$ sudo usermod -aG docker $USER
$ newgrp docker
ئاگاداری ئاسایش ئەندامبوون لە گرووپی docker واتە دەسەڵاتی root لەسەر خانەخوێ. لەسەر سێرڤەری هاوبەش، دۆکەری بێ‌root (rootless) بەکاربهێنە.

06وێنەکان (Images)

وێنە کۆمەڵێک چینی نەگۆڕیە (read-only layers) کە لەسەر یەک دانراون، لەگەڵ فایلێکی JSONی ڕێکخستن. هەر فەرمانێکی Dockerfile کە فایلی دەگۆڕێت، چینێکی نوێ دروست دەکات.

پێکهاتەی وێنەیەک: ┌─────────────────────────────────┐ │ Container (writable layer) │ ← تەنها ئەمە دەگۆڕدرێت ├─────────────────────────────────┤ │ Layer 4: CMD ["node", "app"] │ ├─────────────────────────────────┤ │ Layer 3: COPY . . │ ├─────────────────────────────────┤ │ Layer 2: RUN npm install │ ├─────────────────────────────────┤ │ Layer 1: FROM node:20-alpine │ ← بنەڕەت └─────────────────────────────────┘ هەموو چینەکان هاوبەشن لە نێوان وێنەکاندا. بۆیە داگرتنی nginx:alpine پس از alpine خێرایە!

داگرتن و بینین

$ docker pull nginx:1.27-alpine
$ docker image ls
$ docker image ls --format "table {{.Repository}}\t{{.Tag}}\t{{.Size}}"
ڕوونکردنەوە
docker pull IMG:TAG وێنەکە لە registry دەگرێت و لە لۆکاڵ پاشەکەوت دەکات. ئەگەر پێشتر هەبوو، تەنها چینە نوێیەکان دەگرێت.
docker image ls لیستی هەموو وێنە لۆکاڵییەکان. هاوشێوەی docker images.
--format کۆنترۆڵی دەرئەنجام بە Go template. بۆ سکریپت و خواندن زۆر بەکەڵکە.

پشکنین و تێگەیشتن

$ docker image inspect nginx:1.27-alpine
$ docker image inspect -f '{{.Config.Cmd}}' nginx:1.27-alpine
$ docker history nginx:1.27-alpine
جیاوازی ئەم سێ فەرمانە
inspect هەموو زانیارییەک لەسەر وێنە — config، env، entrypoint، layers. دەرئەنجامەکی JSONی گەورەیە.
inspect -f تەنها بەشێکی دیاریکراو. بۆ نموونە .Config.Cmd تەنها CMDی وێنە نیشان دەدات.
history لیستی چینەکان بەپێی کات. فەرمانی هەر چینێک و قەبارەکەی. بۆ دۆزینەوەی چینە گەورەکە زۆر بەکەڵکە.

تاگ، سڕینەوە، پاککردنەوە

$ docker tag myapp:latest registry.example.com/team/myapp:1.0.0
$ docker image rm nginx:1.27-alpine
$ docker image prune -a
ئاستی بەرز latest درۆیە. وێنەکان بۆ بەرهەمهێنان بە تاگی دیاریکراو یان باشتر بە digest تاگ بکە: nginx@sha256:.... Digest نەگۆڕە — هەمان بایت هەمیشە.

07کۆنتەینەرەکان

ئەمە بەشەکەیە کە ڕۆژانە بەکاریدەهێنی.

فلاگەکانی docker run

فلاگماناکاتێک بەکاریدەهێنی
-dDetached — لە پاشبنەما کار بکاتسێرڤەر، داتابەیس، هەر شتێکی بەردەوام
-itInteractive + TTY — شێڵێک بداتێدۆزینەوەی کێشە، کارکردن بە دەستی
--rmکۆنتەینەر بسڕەوە کاتێک کۆتایی هاتفەرمانەکانی کاتی، تاقیکردنەوە
--nameناوی جێگیرکاتێک دەتەوێت دواتر پەیوەندی پێوە بکەیت
-p H:Cپۆرتی خانەخوێ → کۆنتەینەردەستگەیشتن لە دەرەوە
-e K=Vگۆڕاوەی ژینگەڕێکخستن، نهێنییەکان (نەخێر بۆ نهێنی)
-vڤۆلیووم یان bind mountداتای بەردەوام، کۆدی گەشەپێدان
--networkپەیوەندیکردن بە شەبەکەیەککاتێک چەند کۆنتەینەر پێویستە قسە بکەن
--restartسیاسەتی دووبارە هەڵسانەوەبەرهەمهێنان — unless-stopped
--memoryسنووری RAMهەمیشە لە بەرهەمهێنان

دەستپێکردن و بینین

$ docker run -d --name web -p 8080:80 nginx:1.27-alpine
$ docker ps
$ docker ps -a
$ docker ps -aq
جیاوازی ئەم سێ فەرمانە
docker ps تەنها کۆنتەینەرەکانی کارا. ئەگەر هیچ نیشان نەدرا، واتە هیچ کۆنتەینەرێک ناچالاکە.
docker ps -a هەموو کۆنتەینەرەکان، لەوانە ئەوانەی مردوون. بۆ دۆزینەوەی کێشە زۆر گرنگە.
docker ps -aq تەنها IDی کۆنتەینەرەکان، بێ هێڵی سەرەوە. بۆ سکریپت و فەرمانی وەک docker rm $(docker ps -aq) بەکەڵکە.

چوونە ناوەوە و بینینی لۆگ

$ docker logs -f --tail 50 web
$ docker exec -it web sh
$ docker top web
$ docker stats
هەر یەکێک بۆ چییە
docker logs دەرئەنجامی پرۆسێسی سەرەکی کۆنتەینەر. -f = شوێنکەوتنی زیندوو، --tail 50 = تەنها ٥٠ هێڵی کۆتایی.
docker exec فەرمانێک لەناو کۆنتەینەری کارا جێبەجێ دەکات. -it = شێڵی کارلێککردوو. sh بەکاربهێنە نەک bash لە Alpine.
docker top پرۆسێسەکانی ناو کۆنتەینەر لە ڕوانگەی خانەخوێوە. بۆ دڵنیابوون لەوەی پرۆسێسەکە هەیە.
docker stats بەکارهێنانی زیندووی CPU، RAM، شەبەکە. وەک top بەڵام بۆ کۆنتەینەرەکان. --no-stream بۆ یەک جار.

وەستان، سڕینەوە، کۆپیکردن

$ docker stop web
$ docker start web
$ docker restart web
$ docker rm web
$ docker rm -f web
$ docker cp web:/etc/nginx/nginx.conf ./nginx.conf
جیاوازی stop و rm
docker stop SIGTERM دەنێریت، دوای ١٠ چرکە SIGKILL. کۆنتەینەر دەمرێت بەڵام نامێنێتەوە.
docker start کۆنتەینەرێکی وەستاو دووبارە هەڵدەستێنێت. داتای ناوەوە دەمێنێتەوە (لە writable layer).
docker rm کۆنتەینەر دەسڕێتەوە. داتای writable layer لەناو دەچێت. پێویستە سەرەتا stop بکرێت.
docker rm -f stop + rm لە یەک فەرماندا. زۆر بەکەڵکە بەڵام ئاگاداربە — داتا لەناو دەچێت.
docker cp کۆپیکردنی فایل لە نێوان کۆنتەینەر و خانەخوێ. بۆ دەرهێنانی config یان لۆگ بەکەڵکە.

خولگەی ژیان

docker create ──► Created ──► docker start ──► Running │ docker pause │ docker stop ▼ Paused ──► Exited ──► docker rm ──► gone
تێبینی پرۆسێسی سەرەکی کۆنتەینەر PID 1ە لەناویدا. ئەگەر ئەو پرۆسێسە بمرێت، کۆنتەینەر دەمرێت — تەنانەت ئەگەر daemonێک لەناویدا هەڵدەستێنی. یەک کۆنتەینەر، یەک بەرپرسیارێتی.

08داتا — ڤۆلیووم و Bind Mount

کۆنتەینەرێک بسڕدرێتەوە، writable layerەکەی لەگەڵ خۆی دەبات. ئەگەر داتا دەبێت بمێنێتەوە، دەبێت لە دەرەوەی کۆنتەینەر بێت. سێ ڕێگا هەیە:

جۆرلە کوێیەبۆچی بەکاریدەهێنی
Named volumeشوێنی بەڕێوەبراو لەلایەن دۆکەربنکەدراوە، فایلی بەکارهێنەر — داتای ڕاستەقینە
Bind mountڕێچکەیەک لەسەر خانەخوێگەشەپێدانی لۆکاڵ، فایلی ڕێکخستن
tmpfsتەنها لە RAMنهێنییەکان، شوێنی کاتی، کاش

Named Volumes

$ docker volume create pgdata
$ docker volume ls
$ docker volume inspect pgdata
$ docker run -d --name db \
    -e POSTGRES_PASSWORD=secret \
    -v pgdata:/var/lib/postgresql/data \
    postgres:16-alpine
ڕوونکردنەوەی هەنگاوەکان
volume create ڤۆلیوومێک بە ناوی دیاریکراو دروست دەکات. دۆکەر بەڕێوەدەبات، تۆ پێویست ناکات ڕێچکەکە بزانیت.
volume inspect ناونیشانی ڕاستەقینەی لەسەر دیسکی خانەخوێ نیشان دەدات (/var/lib/docker/volumes/…).
-v name:/path ڤۆلیوومەکە بدە بە ڕێچکەیەکی ناو کۆنتەینەر. داتا لەوێ دەنووسرێت و دوای سڕینەوەی کۆنتەینەر دەمێنێتەوە.

Bind Mounts

$ docker run --rm -it \
    --mount type=bind,source="$(pwd)",target=/app,readonly \
    -w /app node:20-alpine sh
بۆچی --mount باشترە لە -v
--mount ڕوون و ئاشکرایە. ئەگەر ڕێچکەی سەرچاوە نەبوو، بە هەڵە ڕادەوەستێت. باشترە بۆ سکریپت.
-v کورتترە بەڵام ئەگەر ڕێچکە نەبوو، دۆکەر بەبێ مەودا فایلێک دروست دەکات. مەترسیدارە.
readonly کۆنتەینەر ناتوانێت بنووسێت. باشە بۆ فایلی ڕێکخستن و کۆدی گەشەپێدان.

پاشەکەوتکردنی ڤۆلیووم

# باکئەپ
$ docker run --rm -v pgdata:/data -v "$(pwd)":/backup alpine \
    tar czf /backup/pgdata-$(date +%F).tgz -C /data .

# گەڕاندنەوە
$ docker run --rm -v pgdata:/data -v "$(pwd)":/backup alpine \
    tar xzf /backup/pgdata-2024-01-01.tgz -C /data

ئەم کۆدە کۆنتەینەرێکی کاتی Alpine هەڵدەستێنێت کە دوو ڤۆلیوومی هەیە: /data (ڤۆلیوومی پاشەکەوت) و /backup (ڕێچکەی خانەخوێ). دواتر tar فایلەکان کۆپی دەکات.

09شەبەکە (Network)

درایڤەرڕەفتار
bridgeبنەڕەت. سوێچێکی ڤێرچواڵی تایبەت لەسەر خانەخوێ.
hostهیچ جیاکردنەوەیەک نییە — کۆنتەینەر شەبەکەی خانەخوێ بەکاردەهێنێت.
noneهیچ شەبەکەیەک نییە.
overlayشەبەکەی چەند خانەخوێ (بۆ کۆمەڵە).
macvlanکۆنتەینەر IPی ڕاستەقینەی لەسەر LAN دەگرێت.

دروستکردنی شەبەکەی تایبەت — هەمیشە ئەمە بکە

$ docker network create appnet
$ docker network ls
$ docker network inspect appnet
$ docker run -d --name db  --network appnet -e POSTGRES_PASSWORD=secret postgres:16-alpine
$ docker run -d --name api --network appnet -p 3000:3000 myapi:1.0
بۆچی شەبەکەی تایبەت گرنگە
DNS خودکار لەسەر شەبەکەی تایبەت، دۆکەر ناوی کۆنتەینەرەکان وەک ناوی DNS بەکاردەهێنێت. api دەتوانێت بە db:5432 پەیوەندی بکات — بەبێ IP.
جیاکردنەوە کۆنتەینەرەکانی شەبەکەی تر ناتوانن بەم شەبەکەیە بگەن. ئەمە ئاسایش زیاد دەکات.
bridge بنەڕەتی DNSی تێدا نییە — تەنها بە --link (کۆن) یان IP کار دەکات. بۆیە هەمیشە شەبەکەی تایبەت دروست بکە.

پشکنینی پەیوەندی

$ docker exec -it api sh -c "nslookup db"
$ docker network connect appnet web
$ docker network disconnect appnet web
$ docker network rm appnet

بڵاوکردنەوەی پۆرت — ئەمە دوو جار بخوێنەوە

$ docker run -p 8080:80 nginx
$ docker run -p 127.0.0.1:8080:80 nginx
$ docker run -p 8080:80/udp nginx
سێ شێوازی پۆرت
-p 8080:80 هەموو ئینتەرفەیسەکان (0.0.0.0). لە تۆڕەکەوە دەستگەیشتن هەیە. مەترسیدارە لەسەر ئینتەرنێت.
-p 127.0.0.1:8080:80 تەنها لە localhost. باشترین هەڵبژاردن لەگەڵ reverse proxy (Nginx، Caddy).
/udp بۆ UDP. بەبێ ئەمە، پۆرت UDP دەبێت. بۆ HTTP، DNS، WebRTC گرنگە.
مەترسی -p 8080:80 بە شێوەی بنەڕەتی 0.0.0.0 بەستنەوە دەکات — پۆرتەکەت بۆ هەموو تۆڕەکە کراوەیە. لەسەر سێرڤەری گشتی هەمیشە 127.0.0.1 بەکاربهێنە.

10Dockerfile

Dockerfile شوێنێکە کە جیاوازی گەورە لە نێوان ئاستی سەرەتایی و ئاستی بەرزدا دەردەکەوێت. Dockerfileیەکی کارا ١٠ خولەکی پێویستە. یەکێکی باش تێگەیشتنی چینەکان، کاش و ئاسایشی پێویستە.

ڕوونکردنەوەی هەموو فەرمانەکان

فەرمانمەبەست
FROMوێنەی بنەڕەت. یەکەم فەرمانی نا-کۆمێنت.
WORKDIRڕێچکەی کارکردن دیاری دەکات و دروستی دەکات.
COPYفایل لە build context دەگوازێتەوە بۆ ناو وێنە.
ADDوەک COPY بەڵام tar دەکاتەوە و URL دەگرێت. زۆرجار پێویست نییە.
RUNفەرمانێک لە کاتی build جێبەجێ دەکات، چینێک دروست دەکات.
ENVگۆڕاوەی ژینگە لە وێنەدا جێگیر دەکات.
ARGگۆڕاوەی کاتی build — لە runtime نابێت.
EXPOSEتەنها دۆکیومێنتە — پۆرت بڵاو ناکاتەوە.
USERدەسەڵات کەم دەکاتەوە بۆ ئەو بەکارهێنەرە.
VOLUMEخاڵێکی mount دیاری دەکات.
ENTRYPOINTفەرمانی جێگیری کۆنتەینەر.
CMDئارگیومێنتی بنەڕەت — لە CLI دەگۆڕدرێت.
HEALTHCHECKچۆن دۆکەر بزانێت کۆنتەینەر تەندروستە.

Dockerfileی بەرهەمهێنانی فرە-قۆناغی

# syntax=docker/dockerfile:1

FROM node:20-alpine AS deps
WORKDIR /app
COPY package*.json ./
RUN --mount=type=cache,target=/root/.npm npm ci

FROM node:20-alpine AS build
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build

FROM node:20-alpine AS runtime
ENV NODE_ENV=production
WORKDIR /app
RUN addgroup -S app && adduser -S app -G app
COPY --from=build /app/dist ./dist
COPY --from=deps  /app/node_modules ./node_modules
USER app
EXPOSE 3000
HEALTHCHECK --interval=30s --timeout=3s --start-period=10s \
  CMD wget -qO- http://127.0.0.1:3000/health || exit 1
CMD ["node", "dist/server.js"]
ڕوونکردنەوەی هەنگاوەکان
AS deps قۆناغی یەکەم — تەنها پێداویستییەکان دابمەزرێنە. ئەم قۆناغە تەنها package.json دەگۆڕێت.
--mount=type=cache کاشی npm لە نێوان buildەکان پاشەکەوت دەکات. خێرایی زۆر زیاد دەکات.
AS build قۆناغی دووەم — کۆد build دەکات. node_modules لە depsەوە دەگرێت.
AS runtime قۆناغی کۆتایی — تەنها dist و node_modules. build tools لەناویدا نین.
adduser بەکارهێنەرێکی نا-root دروست دەکات. هەمیشە USER app بەکاربهێنە.
HEALTHCHECK هەر ٣٠ چرکە endpointی /health پشکنین دەکات. ئەگەر شکست هێنا، کۆنتەینەر ناتەندروستە.

ENTRYPOINT vs CMD — یاساکە

# ENTRYPOINT = چی ڕادەکات. CMD = ئارگیومێنتی بنەڕەت.
ENTRYPOINT ["nginx"]
CMD ["-g", "daemon off;"]

# docker run myimg -t          → nginx -t        (CMD گۆڕدرا)
# docker run myimg            → nginx -g "daemon off;"
جیاوازی بنەڕەتی
CMD دەتوانرێت لە CLI بگۆڕدرێت. تەنها ئارگیومێنتی بنەڕەتە.
ENTRYPOINT نەگۆڕە. ئەوەیە کە هەمیشە جێبەجێ دەبێت. docker run myimg sh = nginx sh، نەک sh.
--entrypoint دەتوانرێت ENTRYPOINT لە CLI بگۆڕدرێت: docker run --entrypoint sh myimg.
فۆرمی exec هەمیشە فۆرمی JSON بەکاربهێنە CMD ["node","server.js"]، هەرگیز CMD node server.js نا. فۆرمی شێڵ پرۆسێسەکەت لە /bin/sh -c دەپێچێتەوە، بۆیە SIGTERM هەرگیز ناگاتە ئەپەکەت و docker stop ١٠ چرکە چاوەڕێ دەکات.

.dockerignore — ئەمە لەبیر مەکە

.git
node_modules
dist
*.log
.env
Dockerfile
docker-compose*.yml
coverage
.DS_Store

بەبێ ئەمە، هەموو build context هەر جارێک بۆ daemon دەنێردرێت — هێواش، و خراپتر، لەوانەیە بە هەڵە .envەکەت لە وێنەیەکی گشتیدا دابنێیت.

Build

$ docker build -t myapp:1.0.0 .
$ docker build -t myapp:1.0.0 -f Dockerfile.prod .
$ docker build --no-cache -t myapp:1.0.0 .
$ docker build --target build -t myapp:debug .
فلاگەکانی build
-t name:tag ناو و تاگ بۆ وێنەی دروستکراو. بەبێ ئەمە، وێنەکە تەنها IDی هەیە.
-f FILE Dockerfileی تر بەکاربهێنە. بۆ نموونە Dockerfile.prod جیا لە Dockerfileی گەشەپێدان.
--no-cache کاش نەکەیت. هەموو چینەکان لە نوێوە دروست دەکرێن. بۆ دڵنیابوون لە تازەیی.
--target تەنها تا قۆناغێکی دیاریکراو build بکە. بۆ دۆزینەوەی کێشە زۆر بەکەڵکە.

11Docker Compose

Compose ئەپلیکەیشنێکی چەند-کۆنتەینەر لە یەک فایلدا ڕوون دەکاتەوە. وەشانی نوێ (docker compose، pluginی v2) دیگر پێویستی بە version: نییە — بیسڕەوە.

compose.yaml

services:
  web:
    build: .
    ports:
      - "8080:3000"
    environment:
      NODE_ENV: production
      DATABASE_URL: postgres://app:secret@db:5432/app
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: secret
      POSTGRES_DB: app
    volumes:
      - dbdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app"]
      interval: 10s
      timeout: 5s
      retries: 5

volumes:
  dbdata:
ڕوونکردنەوەی بەشەکان
services لیستی کۆنتەینەرەکان. هەر یەکێک ناوێکی هەیە (web، db).
build: . لە Dockerfileی ڕێچکەی ئێستا build بکە. جیا لە image: کە وێنەیەکی ئامادە بەکاردەهێنێت.
depends_on پەیوەندی. بەڵام بەبێ condition تەنها چاوەڕێی هەڵسانەوە دەکات، نەک ئامادەیی.
condition: service_healthy چاوەڕێ دەکات داتابەیسەکە تەندروست بێت. ئەمە کێشەی "connection refused" چارەسەر دەکات.
volumes ڤۆلیوومەکانی بەردەوام. لە خوارەوە دیاری دەکرێن.

فەرمانەکانی ڕۆژانە

$ docker compose up -d
$ docker compose up -d --build
$ docker compose ps
$ docker compose logs -f web
$ docker compose exec web sh
$ docker compose restart web
$ docker compose down
$ docker compose down -v
$ docker compose config
جیاوازی فەرمانەکان
up -d هەموو services هەڵدەستێنێت لە پاشبنەما. بەبێ -d، لۆگەکان لە بەردەمتدان.
up --build وێنەکان دووبارە build دەکات پێش هەڵسان. پێویستە کاتێک Dockerfile گۆڕدرا.
down هەموو کۆنتەینەرەکان دەوەستێنێت و دەیسڕێتەوە. شەبەکەش دەسڕێتەوە.
down -v ڤۆلیوومەکانیش دەسڕێتەوە. داتا لەناو دەچێت — بە وریاییەوە بەکاربهێنە.
config فایلی تەواو-یەکگرتوو نیشان دەدات — لەگەڵ .env. کاتێک "لۆکاڵ کاردەکات بەڵام لە CI نا" لێرەوە دەست پێبکە.
تێبینی depends_on بەبێ condition: service_healthy تەنها چاوەڕێی هەڵسانەوەی کۆنتەینەر دەکات، نەک پەیوەندیکردنی داتابەیس. ئەمە یەکەم هۆکاری "connection refused"ە لە یەکەم هەڵسانەوەدا.

12Registries و تاگەکان

$ docker login ghcr.io
$ docker tag myapp:1.0.0 ghcr.io/team/myapp:1.0.0
$ docker push ghcr.io/team/myapp:1.0.0
$ docker pull ghcr.io/team/myapp:1.0.0
خولگەی گواستنەوە
docker login چوونەژوورەوە بۆ registry. زانیاری لە ~/.docker/config.json پاشەکەوت دەکرێت.
docker tag ناوی نوێ دەداتێ. هەمان وێنەیە بە دوو ناو. پێش push پێویستە.
docker push وێنەکە بۆ registry دەنێریت. تەنها چینە نوێیەکان دەنێردرێن.
docker pull وێنە لە registry دەگرێت. ئەگەر پێشتر هەبوو، تەنها چینە نوێیەکان دەگرێت.

گواستنەوە بەبێ registry

$ docker save myapp:1.0.0 -o myapp.tar
$ docker load -i myapp.tar

# export/import هەموو چینەکان تەخت دەکات — مێژوو و metadata لەناو دەچێت
$ docker export web -o web.tar
$ docker import web.tar myflat:1.0
ئاستی بەرز ستراتیژی تاگکردن کە گەورە دەبێت: 1.2.3 (بەرهەمهێنانی نەگۆڕ)، 1.2 (مینۆری جووڵاو)، sha-abc1234 (کۆمیتمی دیاریکراو)، latest (تەنها بۆ ئاسانکاری، هەرگیز بۆ deploy).

13بەهێزکردنی ئاسایش

بنەڕەت ئاسانە، نەک ئاسایش. هەر دێڕێکی خوارەوە یەک جۆری مەترسی لادەبەرێت.

١. هەرگیز وەک root مەکە

RUN addgroup -S app && adduser -S app -G app
USER app

٢. فایلسیستەمی خوێندنەوە-تەنها + کاپابیلیتی کەمکراوە

$ docker run -d \
    --read-only \
    --tmpfs /tmp \
    --cap-drop ALL \
    --cap-add NET_BIND_SERVICE \
    --security-opt no-new-privileges:true \
    --user 1000:1000 \
    myapp:1.0.0
ڕوونکردنەوەی هەر فلاگێک
--read-only سیستەمی فایلی وێنە ناتوانێت بنووسێت. تەنها tmpfs و ڤۆلیوومەکان.
--cap-drop ALL هەموو دەسەڵاتەکانی لینوکس لادەبەرێت. پاشان تەنها ئەوانەی پێویست زیاد بکە.
no-new-privileges پرۆسێس ناتوانێت دەسەڵاتی زیاتر بەدەست بهێنێت (setuid، file capabilities).
--user 1000:1000 UID/GIDی دیاریکراو. باشترە لە root (0:0).

٣. نهێنییەکان — گۆڕاوەی ژینگە نییە

# خراپ — لە docker inspect و /proc/1/environ دیارە
$ docker run -e DB_PASSWORD=hunter2 myapp

# باشتر — وەک فایل mount بکە

٥. کەمکردنەوەی وێنەی بنەڕەت

بنەڕەتقەبارەئاستی مەترسی
ubuntu:24.04~78 MBگەورە — userlandی تەواو
alpine:3.20~8 MBبچووک — musl libc، busybox
distroless/static~2 MBکەمترین — هیچ شێڵێک نییە
scratch0 MBتەنها باینەری static

لیستی پشکنینی ئاسایش

  • USERی نا-root لە قۆناغی کۆتایی.
  • وێنەی بنەڕەت بە digest دیاریکراو، نەک تاگی جووڵاو.
  • --read-only لە کوێ کە ئەپەکە ڕێگە دەدات.
  • --cap-drop ALL پاشان تەنها ئەوانەی پێویست زیاد بکە.
  • هیچ نهێنییەک لە وێنە، لە ENV، یان لە build args نەبێت.
  • .dockerignore .env، .git، کلیلەکان لادەبەرێت.
  • پشکنینی وێنە لە CI، نەک بە دەست.
  • تەنها ئەو پۆرتانە بڵاو بکە کە پێویستن، بە 127.0.0.1 بەستراوە.

14باشترکردنی خێرایی

کاشی چینەکان: ڕیزبەندی گرنگە

# خراپ — هەر گۆڕانکارییەک لە کۆد، چینی install دەشکێنێت
COPY . .
RUN npm ci

# باش — پێداویستییەکان تا package.json دەگۆڕێت کاش دەکرێن
COPY package*.json ./
RUN npm ci
COPY . .
بۆچی ئەم ڕیزبەندییە گرنگە
Docker caching دۆکەر هەر چینێک بەپێی فەرمان و فایلەکانی پێشوو کاش دەکات. ئەگەر فایلێک بگۆڕدرێت، هەموو چینەکانی دواتر لە نوێوە دروست دەکرێن.
COPY package*.json تەنها package.json و package-lock.json. کۆدی سەرچاوە لە قۆناغی دواتردایە. بۆیە npm ci کاش دەکرێت.

Cache mounts (BuildKit)

# syntax=docker/dockerfile:1
RUN --mount=type=cache,target=/root/.npm npm ci
RUN --mount=type=cache,target=/root/.cache/pip pip install -r requirements.txt
RUN --mount=type=cache,target=/go/pkg/mod go mod download

Multi-stage = وێنەی بچووکتر و ئارامتر

FROM golang:1.23 AS build
WORKDIR /src
COPY . .
RUN CGO_ENABLED=0 go build -o /out/app ./cmd/app

FROM scratch
COPY --from=build /out/app /app
ENTRYPOINT ["/app"]
REPOSITORY TAG SIZE myapp single 812MB myapp multi 6.4MB

$ docker buildx create --use --name multi
$ docker buildx build \
    --platform linux/amd64,linux/arm64 \
    -t ghcr.io/team/myapp:1.0.0 --push .
ئاستی بەرز ئەم فەرمانە وێنەیەک دروست دەکات کە لەسەر هەم amd64 (لینوکسی ئاسایی) و هەم arm64 (Apple Silicon، AWS Graviton) کاردەکات. بەبێ ئەمە، وێنەکەت تەنها لەسەر ئەو ئارکیتێکچەرە کاردەکات کە buildت کردووە.

شکستە باوەکان

هەڵەهۆکاری ڕاستەقینە
port is already allocated شتێک پێشتر لەو پۆرتە گوێی لێیە. docker ps، یان lsof -i :8080.
container exits with 0 immediately پرۆسێسی سەرەکی کۆتایی هات. سێرڤەر دەبێت لە پێشەوە کار بکات.
exit code 137 SIGKILL — زۆرجار OOM killer. --memory زیاد بکە.
exit code 127 فەرمان نەدۆزرایەوە — وێنەی بنەڕەتی هەڵە یان باینەری ون.
exec format error نەگونجاوی ئارکیتێکچەر — بۆ arm64 build کراوە، لەسەر amd64 کاردەکات.
no space left on device docker system prune -a --volumes (وریابە: ڤۆلیوومی بەکارنەهێنراو دەسڕێتەوە).
permission denied on bind mount UID لە نێوان خانەخوێ و بەکارهێنەری کۆنتەینەر جیاوازە.
connection refused between services شەبەکەی هەڵە، یان پێداویستییەکە هێشتا ئامادە نییە.

دۆزینەوەی قووڵ

# شێڵێک لە وێنەیەکی شکاو، بێ entrypoint
$ docker run --rm -it --entrypoint sh myapp:1.0.0

# چی گۆڕدراوە لەناو کۆنتەینەرێکی کارا
$ docker diff web

# بەکارهێنانی سەرچاوە، یەک جار
$ docker stats --no-stream

# بینینی PIDی ڕاستەقینە لەسەر خانەخوێ
$ docker inspect -f '{{.State.Pid}}' web

# پاککردنەوەی تەواو — هیچ شتێک ناشێڵێت
$ docker system prune -a --volumes -f
ڕێگا بەم ڕیزبەندییە دۆزینەوەی کێشە بکە: لۆگ → کۆدی دەرچوون → inspect → شەبەکە → سەرچاوەکان. مەخەریتە سەر خەیاڵ — خوێندنەوە کاتی کەمتر دەبات.
